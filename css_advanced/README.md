# SmileSchool: CSS, advanced

A static landing page for **SmileSchool**, a fictional online school that teaches you how to smile. This project takes the HTML built in *HTML, advanced* and styles it to match a Figma design, using only HTML and CSS (no frameworks, no libraries).

![SmileSchool page preview](images/preview.png)

## What's on the page

- **Header + banner**: logo, navigation links, "Get schooled" hero, call-to-action button and the "Learn from the pros" instructors
- **Quote**: a student testimonial with portrait
- **Videos**: four popular tutorial cards with author, star rating and duration
- **Membership**: four free-plan benefits and a register button
- **FAQ**: four questions in a 2x2 grid
- **Footer**: logo, social links and copyright

## What I practiced

- Adding styles with an external stylesheet (`<link rel="stylesheet" href="styles.css">`)
- Class selectors and keeping CSS specificity low and predictable
- The box model: margin, padding, border, width, `box-sizing`
- Layout with Flexbox
- Reusing shared styles (buttons, round images, section titles) instead of repeating them
