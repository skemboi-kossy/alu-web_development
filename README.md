# alu-web-development

Web development projects for ALU coursework, covering HTML, CSS, and JavaScript fundamentals.

## html_basic

An introduction to HTML: structuring valid pages, working with headings, paragraphs, links, and images, embedding external content, and building a consistent multi-page layout with `<header>`, `<main>`, and `<footer>`.

**Files:**
- `base_index.html` — minimal valid HTML skeleton
- `index.html` — homepage with headings, paragraphs, and a clickable image
- `tweets.html` — secondary page with an embedded tweet

All files are validated against the [W3C Validator](https://validator.w3.org/).
