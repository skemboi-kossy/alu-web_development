# HTML Advanced

## Description

This project rebuilds the **SmileSchool** homepage from a Figma design,
one HTML/CSS/JavaScript project at a time. This task focuses only on the
**HTML structure** of the page — no CSS, no styling, just pure semantic
HTML.

The page is built section by section, following the wireframe:

1. **Header** — logo and navigation links
2. **Banner** — "Get schooled" hero with CTA, plus a "Learn from the pros" block
3. **Quote** — a testimonial with photo and blockquote
4. **Videos** — "Most popular tutorials": 4 video cards with author and rating
5. **Membership** — "Free membership": 4 plan cards
6. **FAQ** — 2 rows of 2 question/answer items
7. **Footer** — logo, social links, and copyright text

No external libraries, frameworks, or build tools are used — only plain
HTML, in line with the project requirements.

## Validation

The markup is written to be W3C compliant. Verify by pasting the file
into the [W3C Markup Validator](https://validator.w3.org/).
